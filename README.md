# Telemedicine & Rural Health – Node.js Prototype

## Features
- Rural-friendly telemedicine dashboard
- Doctor directory
- Appointment booking
- REST API using Express.js
- Appointment data stored in server memory for demo purposes
- Health resources section
- Responsive UI

## Run
1. Install Node.js.
2. Open this folder in VS Code terminal.
3. Run:
   npm install
   npm start
4. Open http://localhost:3000

## API endpoints
GET  /api/doctors
GET  /api/appointments
POST /api/appointments

This is an educational prototype. It does not provide medical diagnosis or emergency care.
